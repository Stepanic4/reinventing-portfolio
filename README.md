# Reinventing Portfolio 2026 🚀

### Interactive Portfolio with Pixel & Glass Physics

## 📱 Project Structure
* **Page 1 (Home):** Profile intro + **Pixel-Disruption Slider** (Legacy Three.js engine ported to React).
* **Page 2 (Works):** Modern Bento Grid. Interactive cards with **Glass-Shatter effect** (Cracks on hover, explodes on click).
* **Page 3 (Resume):** Interactive Resume with "Save as PDF" functionality.

## 🛠 Features
* **Custom Physics:** Transitioning from 2015-era Three.js to modern React-Three-Fiber.
* **Glass UX:** Unique shatter-on-click interaction for project previews.
* **Smart UI:** Language switcher (RU/EN/CZ) and Dark/Light theme engine.
* **Mobile First:** Adaptive layouts with touch-optimized shatter effects.

## ⚙️ Tech Stack
* React 19 + TypeScript + Vite
* Tailwind CSS + Framer Motion
* Three.js (React Three Fiber)

# Nové portfolio 2026 🚀

### Interaktivní portfolio s pixelovou a glass fyzikou

## 📱 Struktura projektu
* **Stránka 1 (Domů):** Úvodní profil + **Posuvník Pixel-Disruption** (Starší engine Three.js portovaný do Reactu).
* **Stránka 2 (Funguje):** Moderní Bento Grid. Interaktivní karty s **efektem rozbití skla** (Praskání při najetí myší, explodování při kliknutí).
* **Stránka 3 (CV):** Interaktivní životopis s funkcí „Uložit jako PDF“.

## 🛠 Funkce
* **Vlastní fyzika:** Přechod z Three.js z roku 2015 na moderní React-Three-Fiber.
* **Glass UX:** Unikátní interakce rozbití při kliknutí pro náhledy projektů.
* **Inteligentní uživatelské rozhraní:** Přepínač jazyků (RU/EN/CZ) a engine s motivy tmavý/světlý.
* **Mobile First:** Adaptivní rozvržení s efekty rozbití optimalizovanými pro dotyk.

## ⚙️ Tech Stack
* React 19 + TypeScript + Vite
* Tailwind CSS + Framer Motion
* Three.js (React Three Fiber)
